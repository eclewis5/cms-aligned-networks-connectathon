Network operators

You run a CMS aligned network. This event is where you test it against other networks.

What to do

  1. Register your network and its endpoints on the registration page.
  2. Read the scenarios. Start with the five minimum scenarios, then try the advanced ones.
  3. Pair up. Check the Participant directory for other networks and arrange runs in the Slack channel.
  4. Record results on the Results page.

Before the event

  • Support Dynamic Client Registration with CMS-signed software statements for Medicare App Library apps and UDAP software statements for all other participant types.
  • Be able to apply the CMS-approved patient matching logic, and respond when any field combination in the CMS patient matching proposal matches.
  • Carry the HL7 Purpose of Use code (PATRQT, TREAT, HPAYMT, CLMATTCH, HOPERAT, HQUALIMP) on every request.
  • Be ready to produce audit logs that show who, when, and Purpose of Use for each query.
  • Know where your HITRUST certification stands. It's required for CMS aligned networks, and its scope must include your production environment that handles PHI.

Good to know

  • Responses must include structured and unstructured data, not only structured data.
  • Networks may coordinate operational matters with each other, but must not impose duplicate trust requirements.
  • Use synthetic data only.
